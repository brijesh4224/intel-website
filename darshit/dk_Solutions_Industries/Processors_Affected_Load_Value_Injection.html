Processors Affected: Load Value Injection

660250
1/27/2020
Latest
Public

 

Intel expects the following processors are potentially affected by the Load Value Injection issue. Refer to the disclosure for software developers and Load Value Injection for further details.

Processors marked with † may support Intel® Software Guard Extensions (Intel® SGX).
