Processors Affected: Special Register Buffer Data Sampling

672855
6/9/2020
Latest
Public

 

In general, Intel® Core™ family microarchitecture client and Intel® Xeon® E3 processors that implement RDRAND and/or RDSEED and are affected by either Microarchitectural Fill Buffer Data Sampling (MFBDS) or Intel® Transactional Synchronization Extensions (Intel® TSX) Asynchronous Abort may also be affected by Special Register Buffer Data Sampling (SRBDS). Refer to the technical documentation for further details. 

More precisely, a processor is affected by SRBDS if its Family_Model and stepping is marked as affected in the following table, with the exception of the specifically marked processors exporting MDS_NO while Intel TSX is available yet not enabled. The latter class of processors are only affected when Intel TSX is enabled by software using TSX_CTRL_MSR, otherwise they are not affected.

Processors marked with † may support Intel® Software Guard Extensions (Intel® SGX).
