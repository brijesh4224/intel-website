ByJennifer L Jiang, Ronald W Green

 

This page contains the experimental Intel® CPU Runtime for OpenCL™ Applications runtime libraries with SYCL* support targeting machines with an Intel® Xeon® processor or Intel® Core™ processor. 

 

 

Supported Operating Systems

See Release Notes or the Intel® CPU Runtime for OpenCL™ Applications Guide for supported operating systems.

 

Download Intel® CPU Runtime for OpenCL™ Applications

Download the required release version of the runtime library for your system. 

 

2025.2 Release

This bundle is for C++ and SYCL developers who want to compile, debug, and use the most popular performance libraries in the Base Kit for Intel CPUs and GPUs. It includes:

  • Windows* 
    • For Intel® 64 applications: Download the installable file w_opencl_runtime_p _2025.2.0.768.exe and double click to install the runtime.
  • Linux*

    • The runtime package for Linux is distributed through APT and YUM. Follow the instructions on Install Using Package Managers to set up the repository and install the package: intel-oneapi-runtime-opencl

2024.2 Release

  • Windows

    • For both IA-32 and Intel® 64 applications: Download the installable file w_opencl_runtime_p_2024 .2.0.980.exe and double click to install the runtime.

 

Notes for Windows Users

Administrative permission is required to install the Intel® CPU Runtime for OpenCL™ Applications on Windows. The installation checks the existing version of your Intel® CPU Runtime for OpenCL™ Applications, and it only installs if the existing version is older than the downloaded version; otherwise, it gives you Repair and Remove functionalities for use. 

The Intel® CPU Runtime for OpenCL™ Applications is installed in the following directory: 

C:\Program Files (x86)\Common Files\Intel\Shared Libraries\
