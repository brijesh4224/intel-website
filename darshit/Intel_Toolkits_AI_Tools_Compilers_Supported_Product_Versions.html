This provides an overview of the access and support for Intel®  Software Developer Tools and Components, including Intel® Compilers for Priority Support Customers.

 

 

Priority Support customers get support for the latest update of the last 3 major versions of compilers and the latest update of the other products. Additionally, priority support customers get access to all the updates of compilers from the last 3 years and all the updates of other products from the last 1 year from their Intel® Registration Center account.

If you do not have Priority Support, you only get access to thelatest version of Intel® Software Developer Tools and you can get support from our Developer Software Forum.

 

Support Definition

Full Support :  Technical Assistance including Security updates (CVEs), functional updates, and OS & IDE related updates as it pertains to the product.

For an issue identified in any version within a major release under Full Support, Intel will provide a fix or a resolution path in an update or otherwise, where reasonable, unless the issue has already been addressed in an update within the same major version.

Limited Support: Minimal Technical Assistance, Security updates (CVEs), and critical functional updates.

For a security or other critical issue identified in any version within a major version under Limited Support, Intel will provide a fix or a resolution path in an update or otherwise, where reasonable, unless the issue has already been addressed in an update within the same major version.

Access to Previous Versions:

If you have Priority Support and would like access to these older versions of products, you can get assistance by opening a ticket through the Online Service Center. Users should upgrade to the latest version of Intel® developer tools. The unsupported versions below do not include the latest functional and security updates. Intel recommends users of these archived products uninstall and discontinue use as soon as possible and upgrade to the latest version.

  • Intel® Parallel Studio XE, All Editions, All Versions

  • Intel® System Studio, All Editions, All Versions

  • Intel® System Studio for Microcontrollers, All Editions, All Versions

  • Intel® HPC and Base Toolkits and components 2023.0.0 and earlier

Each calendar year the list of available versions will be updated and reflected in Intel® Registration Center.
